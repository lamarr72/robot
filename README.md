## Задача 3  	
*Профиль* — это состояние окон приложения (закрыто/открыто, положение на экране, развёрнутое/свёрнутое состояние).
- [ ] В методе выхода из приложения сохранять в файл текущий профиль. 
- [ ] При запуске приложения следует восстанавливать профиль из файла.
- [ ] При запуске приложения необходимо выводить предупреждение о наличии сохранённого профиля и предлагать его восстановить (Да/Нет).

## Задача 4
Загрузка робота извне

- [ ] Реализация задаёт как характеристики и поведение робота, так и особенности его визуализации (цвет, форма и т.п.).
